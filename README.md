# mahmoud-moosa.github.io

Personal portfolio for Mahmoud Mousa — IT Helpdesk professional transitioning into SOC / security analyst work.

## Structure

```
index.html            Home page (about, skills, contact)
projects.html          Case-file style write-ups of projects
assets/css/style.css   Shared styles
assets/js/main.js      Mobile nav, terminal type-in effect, screenshot lightbox
assets/img/            Photos & screenshots
```

## Local preview

Just open `index.html` in a browser — no build step required.

## Deploy

Push to the `main` branch of `mahmoud-moosa.github.io` and GitHub Pages will publish it automatically at:

https://mahmoud-moosa.github.io
